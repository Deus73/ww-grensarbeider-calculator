# WW Grensarbeider Calculator

Een responsive Nederlandstalige webapp voor een **indicatieve** Nederlandse WW-berekening bij volledige werkloosheid van grensarbeiders die in Nederland wonen en in België werken.

## Functies
- Invoer van Belgisch brutomaandloon, arbeidsjaren, uren en situatie.
- Indicatie van de bruto-WW gedurende de eerste twee maanden (75%) en daarna (70%).
- Geschatte duur en totale bruto-uitkering, met waarschuwingen over de beperkingen.
- Afdrukken of opslaan als PDF via de browser.
- Werkt zonder server, cookies of externe scripts.

**Belangrijk:** de app is geen officiële UWV-berekening. De werkelijke berekening hangt onder meer af van dagloon, maximumdagloon, meetellende jaren, buitenlandse looncomponenten en individuele omstandigheden. Een betrouwbare netto-uitkomst is zonder aanvullende gegevens niet mogelijk.

## Publicatie met GitHub Pages
1. Ga naar **Settings → Pages**.
2. Kies **Deploy from a branch**.
3. Kies branch **main**, map **/(root)** en klik op **Save**.
4. De website wordt bereikbaar op https://deus73.github.io/ww-grensarbeider-calculator/ nadat GitHub Pages is gepubliceerd.
